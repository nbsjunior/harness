## Install

1. Download **`toddspect-vscode-0.1.9.vsix`** from [GitHub Releases](https://github.com/nbsjunior/todd/releases/tag/v0.1.9) (~18.8 MB on disk).
2. Optional: verify with **`toddspect-vscode-0.1.9.vsix.sha256`** on the release.
3. VS Code / Cursor: **Extensions → … → Install from VSIX**.

If you see *"End of central directory record signature not found"*, the file is truncated (common with OneDrive or interrupted download). Re-download from GitHub or run `npm run package:vsix:release` and install from `%LOCALAPPDATA%\ToddSpectRelease\`.
